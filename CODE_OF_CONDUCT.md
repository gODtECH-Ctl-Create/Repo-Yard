# Code of Conduct

Repo Yard is a learning space.

We want beginners to ask basic questions without embarrassment and experienced contributors to explain things without talking down to people.

Expected behaviour:
- Be respectful.
- Review the work, not the person.
- Explain disagreements with evidence.
- Help learners understand the reason behind a change.
- Avoid insults, harassment, and gatekeeping.
- Give credit when building on someone else's work.

Maintainers may remove content or participation that harms the learning environment.
