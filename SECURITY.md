# Security

Repo Yard is a public learning repository.

Never commit passwords, API keys, access tokens, private keys, session cookies, or personal authentication data.

If you accidentally commit a secret:
1. Revoke or rotate it immediately.
2. Do not rely on deleting the file alone.
3. Tell a maintainer privately so the incident can be handled.
4. Check repository history because Git retains old commits.

For practice, use fake values such as `YOUR_TOKEN_HERE`.
