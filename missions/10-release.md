# Mission 10 — Ship a Release

## Goal

Practice the versioning path from a merged change to a release.

Create or use a harmless practice repository or test branch and mark a meaningful commit:

```bash
git tag v0.1.0
git push origin v0.1.0
```

Then create a GitHub Release using that tag.

**Success condition:** explain the difference between a commit, a tag, and a GitHub Release.
