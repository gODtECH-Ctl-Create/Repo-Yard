# Mission 06 — Review and Update a Pull Request

## Goal

Experience the full review loop.

Open a practice PR and ask a maintainer or learning partner to leave one useful review comment.

Respond by editing locally, committing, and pushing to the same branch:

```bash
git add .
git commit -m "fix: address review feedback"
git push
```

Then reply to the review comment.

**Success condition:** the original PR contains a follow-up commit and a clear reply explaining what changed.
