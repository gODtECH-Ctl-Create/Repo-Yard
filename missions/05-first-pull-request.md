# Mission 05 — Open Your First Pull Request

## 🎯 Objective

Create a real PR from a feature branch and give a reviewer enough context to work with you.

## Scenario

You have a focused change and need another person to review it before it reaches `main`.

## Tasks

1. Pick a small documentation change from an Issue, or create a learning-focused Issue.
2. Create a branch.
3. Make the change locally.
4. Commit it.
5. Push it.
6. Open a PR into `main`.
7. Put `Mission: M05` in the PR body.
8. Use the Repo Yard PR template.
9. Link the Issue with `Closes #<issue>` when appropriate.

## ✅ Checkpoints

- [ ] Branch is focused.
- [ ] Commit has a useful message.
- [ ] Remote branch exists.
- [ ] Pull Request is open.
- [ ] PR explains what changed, why, and how it was tested.
- [ ] Mission ID is present.

## 🔎 Evidence

The Pull Request is the primary evidence.

## 🤖 Verification

RYOS can see the PR, branch, author and merge state. It can update your Journey when the PR merges.

**Reward:** +150 XP
