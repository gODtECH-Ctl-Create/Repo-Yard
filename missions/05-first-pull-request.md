# Mission 05 — Open Your First Pull Request

## Goal

Create a real PR from a feature branch.

## Do

1. Pick a small documentation change from an Issue, or create a learning-focused Issue.
2. Create a branch.
3. Make the change locally.
4. Commit it.
5. Push it.
6. Open a PR into `main`.
7. Use the Repo Yard PR template.
8. Add `Closes #<issue>` when appropriate.

**Success condition:** a maintainer can understand your change without opening your editor or messaging you for basic context.
