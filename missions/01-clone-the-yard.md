# Mission 01 — Clone the Yard

**Difficulty:** 🌱 Beginner

## 🎯 Objective

Get Repo Yard onto your computer and understand the relationship between your local clone and its remote.

## Do

```bash
git clone https://github.com/gODtECH-Ctl-Create/Repo-Yard.git
cd Repo-Yard
git status
git remote -v
git branch --show-current
git log --oneline -5
```

## ✅ Checkpoints

- [ ] The repository exists locally.
- [ ] You can identify your current branch.
- [ ] You can explain what `origin` points to.
- [ ] You can identify where the local repository stores its history.

## 🔎 Evidence

Your local clone and command output are self-checked. Later missions create stronger GitHub-visible evidence.

Record questions or blockers in your Journey Issue.

## 🤖 Verification

RYOS cannot see your local terminal. Do not mistake a self-check for automated proof.
