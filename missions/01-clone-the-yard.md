# 🎯 Mission 01: Clone the Yard

**Difficulty:** 🌱 Beginner

Get Repo Yard onto your computer.

```bash
git clone https://github.com/gODtECH-Ctl-Create/Repo-Yard.git
cd Repo-Yard
git status
```

Then run:

```bash
git remote -v
```

### ✅ Success condition

You can explain:

- where your local copy lives
- what branch you are on
- what remote points to GitHub
