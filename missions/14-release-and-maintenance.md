# Mission 14 — Ship and Maintain

## 🎯 Objective

Move a repository from merged work to a maintained release.

## 🧩 Scenario

A useful change has been merged. A user needs a version they can identify, understand and return to.

## 📋 Tasks

1. Create an intentional version tag.
2. Push the tag.
3. Create a GitHub Release from that tag.
4. Write useful release notes.
5. Review the repository for stale branches, broken documentation and outdated automation.
6. Make one small maintenance improvement in a Pull Request.
7. Put `Mission: M14` in the maintenance PR body.

## ✅ Success condition

You can show a real tag, a GitHub Release and a maintenance PR.

## 🔎 Evidence

Link the tag, release and maintenance Pull Request.

## 🤖 Verification

GitHub can verify tags, releases and Pull Requests.
