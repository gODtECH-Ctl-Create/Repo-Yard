# 📚 Repo Yard Course Map

Repo Yard is a real Git/GitHub workshop.

Read a lesson, perform its mission on a real repository, prove the requested evidence, then advance.

## Learning loop

**Learn → Try → Verify → Complete → Celebrate → Unlock → Advance**

## Gates

| Gate | Missions | Outcome |
|---|---|---|
| 🟢 Git Basics Complete | M00–M04 | I can safely work with Git locally. |
| 🔵 Contributor Ready | M05–M08 | I can work with a real GitHub team. |
| 🟠 Problem Solver | M09–M11 | I can recover and control repository history and structure. |
| 🔴 Repository Engineer | M12–M14 | I understand how a professional repository operates. |
| ⚫ Team Ready | M15 | I can operate a repository, not just run Git commands. |

## Mission standard

Every mission should make five things obvious:

1. what skill is being learned;
2. what the learner actually does;
3. what counts as evidence;
4. what verification can and cannot prove;
5. what comes next.

The machine-readable source of truth is [`course.json`](course.json).

## Evidence rule

Local-only work uses honest self-checks. GitHub-visible work uses repository/API evidence. Collaboration work requires collaboration evidence.

Do not turn a self-reported command into a fake automated verification result.
