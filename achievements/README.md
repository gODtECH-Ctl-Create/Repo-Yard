# 🏆 Repo Yard Achievements

Achievements are the celebration layer of RYOS.

A badge represents completed course requirements and available evidence.

## Badge catalogue

### 🌱 Git Foundations
Complete M00–M04.

### 🔀 PR Starter
Complete M05–M06.

### 🧯 Problem Solver
Complete M07–M10.

### 🧰 Repository Engineer
Complete M11–M14.

### ⚫ Team Ready
Complete M00–M15 and pass the Maintainer Challenge.

## Requesting a badge

Use your Journey Issue: `/badge git-foundations`

RYOS will tell you what it can verify and what still needs human review.

## Shareable achievements

Verified achievements are intended to become shareable GitHub-native records that link back to Repo Yard.

**Learn → Prove → Earn → Share → Discover Repo Yard**
