**Learn Git and GitHub by actually using Git and GitHub.**

The **repository is the classroom**. The website is only the front door and map.

## 🚀 Start learning

Open the [Start a Repo Yard Journey](.github/ISSUE_TEMPLATE/start-journey.md) issue template, or comment:

`/start`

RYOS creates your personal **Learner Journey** Issue. That Journey becomes your control center for current mission, progress, XP, badges, evidence and next action.

Then follow the mission and do the work on your own computer and on GitHub. Nothing important is simulated in the website.

## 🧭 The Yard

| Level | You will learn |
|---|---|
| 🟢 Git Basics | setup, clone, status, staging, commits, branches and sync |
| 🔵 Contributor | Issues, PRs, reviews, updates, conflicts, forks and upstream |
| 🟠 Problem Solver | recovery, history surgery and repository structure |
| 🔴 Repository Engineer | Actions, governance, releases and maintenance |
| ⚫ Team Ready | maintainer challenge and end-to-end repository operation |

Read the [Course Map](COURSE.md), [RYOS](RYOS.md) and machine-readable [course definition](course.json).

## 🏆 The learning loop

**Learn → Try → Verify → Complete → Celebrate → Unlock → Advance**

## 💻 The core workflow

```text
Your computer
  │
  ├─ edit → status → diff → add → commit
  │
  ▼
Your branch / fork
  │
  ▼
Pull Request → checks → review → updates → merge
  │
  ▼
main → tag → release → maintenance
```

## 🤝 Real collaboration

Public learners use:

**Fork → clone → branch → edit → commit → push → Pull Request**

Repo Yard uses GitHub Issues and Pull Requests as real learning evidence.

## 🏆 Achievements

Complete mission requirements, request a badge in GitHub, and share the resulting achievement with a link back to Repo Yard.

See [Achievements](achievements/README.md).

## 🛡️ Rules

- Never commit passwords, API keys, tokens or private keys.
- Do not force-push shared branches unless a mission explicitly teaches the risk.
- Keep PRs focused.
- Explain what you changed and how you tested it.
- Use Issues when you are stuck.
- Be respectful in reviews.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before contributing.
