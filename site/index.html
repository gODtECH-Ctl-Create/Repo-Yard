THE YARD JOURNEY

From “what is push?” to “hand me the repo.”

Each level adds a real piece of the developer workflow. You do not jump straight into advanced commands without understanding where your work lives.

01

Beginner

Git, GitHub, clone, status, diff, staging and commits.

02

Builder

Branches, remotes, tracking branches, push, pull and fetch.

03

Contributor

Issues, Pull Requests, reviews, updates, forks and upstream.

04

Problem Solver

Conflicts, restore, reset, revert, stash and reflog recovery.

05

Advanced

Rebase, cherry-pick, scaffolding, templates and releases.

06

Team Ready

Actions, CODEOWNERS, branch protection, maintenance and open-source habits.

REAL COLLABORATION

GitHub itself becomes the classroom.

Repo Yard does not simulate teamwork with fake buttons. Learners use Issues, branches, Pull Requests and reviews on GitHub itself.

01

Pick an Issue

Find a scoped task with a clear success condition.

02

Claim the work

Use RepoOps to show who is actively working on it.

03

Work locally

Clone, branch, edit, stage, commit and push.

04

Open a PR

Write the context a reviewer actually needs.

05

Review + respond

Read comments, make follow-up commits and resolve threads.

06

Merge safely

Let checks and review protect the shared main branch.
